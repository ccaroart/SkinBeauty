# 肌肤日记

个人用的护肤记录 PWA。所有数据只存在你手机的浏览器里，不上传任何服务器。

## 部署到 GitHub Pages（免费，约 10 分钟）

1. 注册或登录 github.com。
2. 右上角「+」→「New repository」，名字随便起（比如 `skinlog`），选 **Public**，点「Create repository」。
3. 在新仓库页面点「uploading an existing file」，把这个文件夹里的**所有文件和 icons 文件夹**拖进去，点「Commit changes」。
   注意：要上传的是文件本身，`index.html` 必须在仓库最外层，不要多套一层文件夹。
4. 仓库里点「Settings」→ 左侧「Pages」→「Branch」选 `main`、文件夹选 `/ (root)` →「Save」。
5. 等 1–2 分钟，页面顶部会出现网址，形如 `https://你的用户名.github.io/skinlog/`。

> 仓库是公开的，但里面只有程序代码。你的记录和照片只存在手机上，别人打开这个网址看到的是一个空白的新应用。

## 添加到主屏幕

- **iPhone**：用 Safari 打开网址 → 底部「分享」按钮 →「添加到主屏幕」。
- **安卓**：用 Chrome 打开网址 → 右上角菜单 →「安装应用」或「添加到主屏幕」。

之后**只从主屏幕图标打开**。在 iPhone 上，主屏幕版和 Safari 里打开的是两份独立的数据。

## 备份

设置 →「导出备份文件」，选「存储到文件」或发给自己。只包含文字记录和产品，不含照片。
换手机时：在新手机上装好应用 → 设置 →「从备份恢复」。

## 以后想改东西

改完文件重新上传到 GitHub，同时把 `sw.js` 第一行的 `skinlog-v1` 改成 `skinlog-v2`（每次加 1）。
手机上关掉应用再打开两次，就会更新到新版本。数据不受影响。
